# Admin Runner

Windows 管理员权限进程管理工具

## 功能特性

- ✅ 自动以管理员权限启动配置的程序
- ✅ 监控进程状态，崩溃后自动重启（每 15 秒检查一次）
- ✅ 隐藏控制台窗口，后台运行
- ✅ Sentry 日志记录和错误追踪
- ✅ 支持命令行参数
