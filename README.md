# Admin Runner

Windows 管理员权限进程管理工具

## 干什么的？

- 点击程序启动后，会尝试管理员提权
- 然后运行run.txt中的程序
- 如果run.txt里面的程序退出了，会自动重新运行
- 你可以把这个东西添加到开机启动里，可以让所有run.txt里面的程序开机启动，还能防止程序异常退出：D

## 功能特性

- ✅ 自动以管理员权限启动配置的程序
- ✅ 监控进程状态，崩溃后自动重启（每 15 秒检查一次）
- ✅ 隐藏控制台窗口，后台运行
- ✅ Sentry 日志记录和错误追踪
- ✅ 支持命令行参数
